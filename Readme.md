Программа задумывалась для отслеживания приватности ввода конфиденциальной информации в людных местах. Программа по камере ноутбука (пока поддерживается только встроенная камера ноутбука) отслеживает количество лиц вокруг и при превышении допустимого количества сворачивает все открытые окна.
До запуска приложения программа предлагает выбрать какое количество лиц допускается в кадре. Если лиц станет больше, сработает тревога (звуковой сигнал) и все окна свернутся. Звуковой сигнал будет проолжаться до тех пор, пока в кадре будет больше одного лица. 
После того, как звуковой сигнал пропадет, окно с приложением камеры нужно развернуть. Можно разворачивать нужные окна. После ручного разворачивания окна с программой, программа опять готова защищать вашу приватность.


Что исправлено в v1.1

Добавлены find_window_handle() и is_window_minimized() — через WinAPI (FindWindowW/IsIconic) программа находит своё окно OpenCV и проверяет, свёрнуто ли оно.
Флаг windows_minimized по-прежнему предотвращает повторную отправку Win+D, пока окна свёрнуты (иначе они бы развернулись).
Когда пользователь вручную разворачивает окно программы, детектор состояния замечает, что окно больше не свёрнуто (IsIconic = false), и:
сбрасывает windows_minimized и minimize_confirmed;
пишет в консоль «Окно восстановлено — автосворачивание снова активно»;
при сохраняющемся превышении лиц окна сразу сворачиваются снова.
Добавлена защита от гонки: после отправки Win+D программа ждёт фактического сворачивания окна (minimize_confirmed), и только затем начинает отслеживать ручное восстановление. Если Win+D не сработал за 1.5 с, попытка разрешается повторно.
Сворачивание вынесено из блока звукового сигнала, поэтому после ручного восстановления окна оно срабатывает сразу, не дожидаясь ALERT_COOLDOWN.
